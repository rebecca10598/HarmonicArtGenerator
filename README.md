The Harmonic Art Generator is a browser-based visual experience that fuses math, interactivity, and design into real-time digital art.
Using harmonic sine wave equations, it produces endlessly evolving waveforms that flow in colorful, hypnotic motion. Originally built in Python with Pygame, it’s now reimagined for the web using HTML5, CSS3, and Vanilla JavaScript—fully browser-run, no installation needed. 
It draws complex waveforms on an HTML5 canvas using layered sine functions and randomized values for frequency, amplitude, phase, and harmonics, offering infinite variations. Dynamic color palettes (analogous, complementary, triadic) are rendered via HSV-to-RGB conversion, and animations stay smooth thanks to requestAnimationFrame. 
The canvas is fully responsive, and a soft glow with adjustable line width enhances visual depth. The UI, styled with a sleek glassmorphism effect, features a control panel for regenerating designs and toggling FPS display via keyboard shortcuts. This project highlights how mathematical beauty and modern web tech can merge to create immersive, interactive digital art.
